# Анимации маскота

Положите сюда GIF-файлы с точными именами:

- `science.gif` — наука
- `sport.gif` — спорт
- `art.gif` — искусство
- `general.gif` — общая информация
- `greeting.gif` — приветствие при открытии новой сессии или очистке истории
- `error.gif` — отсутствие информации или ошибка поиска, Jev, Gemma, распознавания или озвучивания

Файлы показываются в области маскота шириной 110 пикселей. Пока GIF отсутствует,
приложение показывает тематическую пиктограмму без текстового названия категории.
Приветствие и ошибка выбираются кодом без обращения к Jev. При отсутствии
релевантного контекста или отказе модели используется та же анимация `error.gif`.
После успешного ответа его тематическая анимация сохраняется до следующего вопроса.
