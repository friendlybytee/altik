# Альтик

Быстрый запуск на Windows: откройте `start.cmd` в папке `code` двойным щелчком.
Из PowerShell в папке `altair altik`: `& .\code\start.cmd`.
В `.env` заполните `TYPESAFE_API_KEY=` своим ключом TypeSafe и перезапустите приложение.
`TYPESAFE_MODEL=jev-latest` выбирает модель Jev; при необходимости можно указать конкретную версию.

Голосовой ввод: откройте «🎙️ Ввести вопрос голосом», разрешите браузеру доступ
к микрофону, запишите вопрос (до 25 секунд), нажмите «Распознать запись».
Проверьте или исправьте текст и нажмите «Отправить голосовой вопрос».
Микрофон в браузере работает на localhost или HTTPS.
GigaAM-v3 загружается через transformers из ai-sage/GigaAM-v3, revision=e2e_rnnt
и затем кешируется. При первом распознавании нужен интернет и место для весов.
Аудио обрабатывается локально; в облачный чат отправляется только текст вопроса
с найденными фрагментами. Работает на CPU, при наличии CUDA используется GPU.
FFmpeg и pyannote.audio для коротких браузерных записей не нужны.
Небольшой pyannote-core нужен проверке импортов transformers.
Код голосового ввода находится в src/speech.py. Версия transformers зафиксирована
по рекомендации авторов модели; torch и torchaudio должны быть совместимы.
Источник: https://huggingface.co/ai-sage/GigaAM-v3

1. Установите Python 3.11 или 3.12. Создайте окружение: `python -m venv .venv`.
2. Активируйте его в PowerShell: `.\.venv\Scripts\Activate.ps1` (Linux/macOS: `source .venv/bin/activate`).
3. Выполните `pip install -r data/requirements.txt`.
4. Установите Ollama с https://ollama.com/download и запустите приложение Ollama (или `ollama serve`, если сервер ещё не запущен).
5. Выполните `ollama pull embeddinggemma`.
6. Укажите `OLLAMA_API_KEY` из https://ollama.com/settings/keys и `TYPESAFE_API_KEY` для Jev в `.env`. Модель облачного чата: `gemma4:31b`.
7. Заполните `data/knowledge.txt` в UTF-8. Разделяйте чанки пустыми строками.
8. Запустите `start.cmd` или `.venv/bin/python -m streamlit run src/app.py` из папки `code`.

Необязательно: положите `assets/mascot.png`, чтобы заменить заглушку маскота.

После поиска Jev классифицирует вопрос и релевантные фрагменты в одну из четырёх
тем: наука, спорт, искусство, общая информация. При расхождении приоритет у
фрагментов. Категория передаётся облачной Gemma как метаданные и выбирает
анимацию маскота; текстовая метка пользователю не показывается. Если релевантных
фрагментов нет, классификация не запускается и показывается отказ с анимацией ошибки.
Если ключ Jev не задан, API недоступен или вернул некорректный результат,
Gemma отвечает без категории, а маскот показывает состояние ошибки.
Классификация выполняется через HTTPS, вопрос и релевантные фрагменты отправляются
в TypeSafe. Ключ остаётся на сервере. Дополнительное окружение или локальные веса
для Jev не нужны; используется уже установленный `requests`.

Правила и примеры находятся в `src/classifier.py`: олимпиада по математике относится
к науке, шахматы — к спорту, хореография — к искусству, общие контакты центра —
к общей информации. При нескольких темах учитываются связь с вопросом и порядок результатов поиска.

Голосовой вывод: включите «Озвучивать ответы» в боковой панели. Новые ответы
получат аудиоплеер; запись сохраняется в истории текущей сессии и не генерируется
повторно при перерисовке страницы. Для воспроизведения нажмите кнопку плеера.
Модель `v5_5_ru.pt` должна лежать в `models/`. Синтез выполняется локально
через `src/tts.py` голосом `eugene`, 48 кГц; модель загружается при первом озвучивании.
Если синтез недоступен, текстовый ответ всё равно отображается.


История хранится только в текущей сессии; каждый вопрос ищется независимо. В облако отправляются вопрос и прошедшие порог фрагменты. После изменения базы индекс обновляется при следующем взаимодействии; после изменения .env перезапустите приложение.

API: https://docs.ollama.com/api/embed и https://docs.ollama.com/api/openai-compatibility.

Сокращения раскрываются перед поиском и отправкой вопроса в облачную модель.
Например, «НТО», «нто», «нац олимпиада» и «нац. олимпиада» превращаются
в «национальная технологическая олимпиада». Остальная часть вопроса сохраняется.
Словарь SEARCH_ALIASES находится в src/rag.py: добавляйте туда пары
`"сокращение": "полное название"` (ключи в нижнем регистре, пробелы одинарные).
Используйте только известные для вашей базы соответствия. Неизвестные сокращения
не угадываются. Порог релевантности по-прежнему применяется.
В блоке найденных фрагментов виден раскрытый поисковый запрос.
После изменения словаря перезапустите Streamlit; переиндексация базы не требуется.

Для коротких названий дополнительно работает поиск по заголовкам: название
в «кавычках» в начале раздела может попасть в контекст даже при низком cosine score.
Учитываются названия из двух и более слов длиной от 10 символов; допускается
одна опечатка при совпадении хотя бы одного целого слова. При неоднозначном
исправлении используется обычный семантический поиск. Более длинное название
имеет приоритет над вложенным: «ПРО Большие вызовы» и «Большие вызовы» различаются.
В debug-блоке показана причина отбора, а score остаётся реальным значением FAISS.
Совпадение названия даёт модели контекст о теме, но не гарантирует, что в нём
есть ответ на любой вопрос об этой теме: при нехватке фактов модель должна отказать.


## Структура проекта

- `src/` — код приложения, поиск, голос и скрипты оценки.
- `data/` — knowledge.txt, knowledge_old.txt, questions.txt, evaluation_results*.csv и requirements.txt.
- `assets/animations/` — GIF-анимации; `assets/mascot.png` — необязательная статичная картинка.
- `models/` — локальная модель озвучивания.
- `tests/` — автоматические проверки.
- `.env`, `.env.example`, `.gitignore`, `.venv`, `start.cmd` и README.md остаются в корне.

Пути ресурсов вычисляются от корня проекта. Оценка вопросов из корня:
`python tests/evaluate_questions.py data/questions.txt`; результат по умолчанию
сохраняется в `data/evaluation_results.csv`.

Для однословного названия учитывается полный заголовок: запрос
«направление искусство» совпадает с «НАПРАВЛЕНИЕ «ИСКУССТВО»» даже при
низкой семантической оценке. Отдельное общее слово не отменяет порог.
